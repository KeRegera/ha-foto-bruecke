# Foto-Brücke für Home Assistant

Home-Assistant-OS-App: Fotos vom Android hochladen und auf dem iPhone mit Aufnahmedatum und Ort sichern.

## Installation

1. Einstellungen → Apps (Add-ons) → **App-Store** → ⋮ → **Repositories**
2. `https://github.com/KeRegera/ha-foto-bruecke` hinzufügen
3. **Foto-Brücke** installieren, starten und „In Seitenleiste anzeigen“ aktivieren

Anleitung: siehe [foto_bruecke/DOCS.md](foto_bruecke/DOCS.md)
